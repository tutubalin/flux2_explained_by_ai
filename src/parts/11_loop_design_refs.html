§ 14The denoising loop — where model.py meets the world

model.py never loops. It answers one question per call: "given this noisy image at this timestep, which way is clean?" The loop lives in sampling.py, and it is short enough to fit in your head. 

for i, t in enumerate(timesteps):
    t_curr, t_prev = t / num_steps, (timesteps[i + 1] if i + 1 < len(timesteps) else 0) / num_steps
    pred = model(img, ids, t_curr, ctx, ctx_ids, guidance)   # ← the file you just read
    img = img + (t_prev - t_curr) * pred                     # one Euler step towards clean

Read the update rule slowly, because it is the whole of rectified flow: the model predicts a velocity — the direction and speed at which the image should move — and the sampler takes one Euler step of size (t_prev − t_curr) along it. At the last step t_prev = 0, landing exactly on the clean latent, which the autoencoder then decodes into pixels. There is no noise injected anywhere: this is an ordinary differential equation being integrated, not a stochastic process.

14.1 · Which timesteps? The logit-normal schedule

The step times are not evenly spaced. get_schedule draws them from a logit-normal distribution shifted by mu, which depends only on the number of image tokens — bigger images get their steps concentrated differently. For a 4096-token image (1024²) with 8 steps the times are

§ 15Why the file looks like this — twelve design decisions

Reading 834 lines you meet a lot of choices that look arbitrary until you see the reason. Here they are, collected.

decisionwherethe reason
Fused projectionsL453, L459One matrix produces q, k, v and the MLP input; another consumes attention and MLP output together. Five matmuls become two, and on a GPU fewer, bigger matmuls are dramatically more efficient.
Modulation computed onceL132–13456 blocks × 3 vectors would mean 168 MLP calls per step; sharing them costs 3 and gives every block the same conditioning signal.
Parameter-free norms + adaLNL464, L470LayerNorm's own gain/bias would fight the modulation. Setting elementwise_affine=False everywhere (81 norms) makes the timestep the sole owner of scale and shift.
No biases anywhereall Linears171 linear layers, all bias=False. At this scale biases contribute nothing measurable and cost memory bandwidth.
fp32 at the edgesL433, L831The network runs in bf16 but the final prediction and the RoPE rotation are cast to fp32: the sampler integrates 50 steps, and tiny systematic errors would accumulate.
4-axis RoPE instead of 1-DL694–707Images are 2-D and references are separated in "time". Four rotation planes with equal dimension splits let one mechanism encode (t, h, w, l) without learned position tables.
A mask instead of two attentionsL808–811Reference isolation could have been a separate code path; expressing it as one boolean mask keeps a single, auditable attention call per configuration.
8 double + 48 singleL96–103Cross-modal weights are only needed while the two streams learn to relate; afterwards shared weights are cheaper. FLUX.1's 19+38 moved to 8+48 — the trade keeps paying.
Cache as a dict of listsL260–264Plain Python structures, one entry per block in block order. No abstraction layer, no registry — the simplest thing that makes cache["double_blocks"][i] obvious.
Dead code left in placeL446, L449self.scale and self.hidden_dim are never read. They survive from an older hand-written attention; deleting them would break checkpoint key compatibility.
assert for shape checksL63, L528Divisibility of hidden by heads is a programming error, not a runtime condition — assert documents it and vanishes under -O.
No dropout, no stochasticity—An inference-only file. Everything deterministic means the KV-cache proof of §13 holds exactly, in floating point, forever.
