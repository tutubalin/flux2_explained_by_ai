FLUX.2, model.py,
every single line.

This is the 833-line file that defines a 32-billion-parameter image generator. It has no training code, no diffusion schedulers, no VAE — just the transformer that sits in the middle of FLUX.2 and predicts, at every step, which direction to push the image. Below, every class, every function and every line is explained from first principles, with hand-drawn diagrams showing exactly how the layers are wired and what shape the data has as it flows between them.

No prior knowledge of diffusion models is assumed. If you know what a matrix multiply does and have seen a bit of Python, you can follow this all the way to the end.

◆ How this article was checked

Every claim marked VERIFIED was produced by actually running the code. The file reproduced here is byte-identical to the upstream source — its git blob hash is 9b1f5b50f8a966d6f4b9ed33b6f125695dc707f0, matching black-forest-labs/flux2@main. I instantiated all three model configs on PyTorch's meta device to count parameters exactly, ran a miniature FLUX.2 end-to-end to trace real tensor shapes, derived the attention isolation pattern empirically by feeding one-hot vectors through the router, and measured the KV-cache error as exactly 0.000e+00. The scripts are src/ref/verify1.py … verify4.py in this repository.

Two further checks run at build time, because this page quotes real line numbers all the way through. Three checkers run on every build and any of them fails the build: src/ref/qa_trace.py verifies that every line-by-line annotation points at lines containing the identifiers it talks about, src/ref/qa_coverage.py verifies that all 692 non-blank lines of the file are shown somewhere, and src/ref/qa_linerefs.py checks all 80 L455-style references in the prose. All three are clean.

One convention to know: numbers and structure are checked against the code, but the file carries almost no comments, so a statement about why the authors chose something is marked inference. There are eleven such marks in 833 lines' worth of explanation — everything else is in the source.
